# Contributing to KumpulMain.id

Terima kasih telah meluangkan waktu untuk berkontribusi pada KumpulMain.id! 🚀

Dokumen ini memberikan panduan untuk Anda yang ingin ikut mengembangkan proyek ini.

## Proses Pengembangan

1.  **Fork repositori ini.**
2.  **Buat branch baru** untuk fitur atau perbaikan Anda (`git checkout -b fitur/nama-fitur`).
3.  **Lakukan perubahan.**
4.  **Tes secara lokal** untuk memastikan perubahan Anda tidak merusak fungsi yang sudah ada.
5.  **Commit perubahan Anda** dengan pesan yang jelas dan deskriptif (`git commit -m 'feat: menambahkan fitur X'`).
6.  **Push ke branch Anda** (`git push origin fitur/nama-fitur`).
7.  **Buat Pull Request (PR)** baru ke branch `main`.

## Pelaporan Bug (Bug Reports)

Saat melaporkan bug, harap sertakan:

*   Langkah-langkah untuk mereproduksi bug.
*   Perilaku yang diharapkan versus perilaku yang terjadi.
*   Screenshot jika relevan (misalnya, masalah tampilan UI).
*   Informasi lingkungan (Browser, OS).

## Permintaan Fitur (Feature Requests)

Kami sangat terbuka untuk ide-ide baru! Saat meminta fitur, tolong jelaskan:

*   Apa tujuan atau masalah yang ingin Anda pecahkan.
*   Bagaimana fitur tersebut seharusnya bekerja.
*   Konteks atau contoh penggunaan.

## Struktur Kode

*   Pastikan untuk mengikuti *style guide* yang sudah ada. Jika untuk frontend (React/Next.js), ikuti standar ESLint dan Prettier.
*   Kami memisahkan logika `booking-web` (frontend) dan `booking-api` (backend). Pastikan Anda memodifikasi di tempat yang benar.

Sekali lagi, terima kasih telah berkontribusi! 🎉
